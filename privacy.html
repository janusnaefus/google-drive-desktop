Personal Google Drive · rclone

Privacy policy

This policy describes the personal Google Drive desktop connection maintained by janusnaefus and this informational website.

Effective 20 October 2026

Google data accessed and used

The owner authorizes rclone through Google's sign-in process. Rclone uses the Google Drive API to access file and folder metadata and file contents so that the owner can browse, open, download, upload, rename, and delete files through the local file manager.

Access is used only to provide this personal file-management functionality. This connection does not use Google Drive data for advertising, profiling, sale, or machine-learning training.

Storage and sharing

OAuth credentials and authorization tokens are stored in the owner's local rclone configuration. Files may be cached or saved on the owner's computer, and the configuration and locally saved files may be included in the owner's backups.

Drive requests and file transfers take place between the owner's computer and Google. This website and its public source repository do not receive or store those credentials, tokens, or Drive files. The connection does not send Drive data to an additional hosted application service.

Control and removal

The owner can stop the local connection at any time and revoke its authorization through Google Account connections. Revocation does not delete files stored in Google Drive.

Local credentials, cached files, downloaded copies, and backup copies remain under the owner's control and can be removed separately when no longer needed.

This website

This static site has no sign-in form, analytics scripts, advertising, or cookies set by its own code. It is hosted on GitHub Pages. GitHub may process technical connection information when serving it, as described in the GitHub General Privacy Statement.

Contact and updates

Questions or corrections can be raised through the website repository. Do not include private files or credentials in public issues. Changes to this policy will be published here with an updated effective date.
